---

## [AI](#ai)

Artificial Intelligence (AI) enables systems to perform tasks that normally require human intelligence, such as reasoning, learning, and decision-making.

We explore AI applications in research, automation, and scalable computing environments.

## [Bash](#bash)

Bash is a Unix shell and command language for automating tasks and managing systems.

It’s essential for scripting workflows, system administration, and DevOps automation.

## [Calico](#calico)

Calico is a networking and network security solution for containers, virtual machines, and native host-based workloads.

It provides scalable networking and robust policy enforcement in Kubernetes environments.

## [Ceph](#ceph)

Ceph is a distributed storage system designed for performance, reliability, and scalability.

It provides unified object, block, and file storage under a single platform.

## [Cilium](#cilium)

Cilium is an open-source networking, observability, and security solution for cloud-native environments.

It uses eBPF technology for efficient and secure data plane operations in Kubernetes.

## [CloudNativePG](#cloudnativepg)

CloudNativePG is a Kubernetes operator for managing PostgreSQL clusters.

It simplifies deployment, scaling, and high availability of PostgreSQL databases in cloud environments.

## [CSS](#css)

Cascading Style Sheets (CSS) define how HTML elements are displayed on web pages.

We use CSS to build clean, responsive, and visually appealing interfaces.

## [Docker](#docker)

Docker is a platform for developing, shipping, and running applications in containers.

It ensures consistent environments across development, testing, and production.

## [etcd](#etcd)

etcd is a distributed key-value store used for configuration management and service discovery.

It serves as the data backbone for Kubernetes and other distributed systems.

## [FumaDocs](#fumadocs)

FumaDocs is a documentation and knowledge management platform tailored for scientific and technical projects.

It helps teams create, organize, and share structured documents efficiently, improving collaboration and reproducibility.

## [Git](#git)

Git is a distributed version control system for tracking changes in source code.

It supports collaborative development and maintains a detailed history of project changes.

## [GitHub/GitLab](#githubgitlab)

GitHub and GitLab are platforms for version control, collaboration, and CI/CD automation.

They enable seamless code review, issue tracking, and DevOps workflows.

## [Golang](#golang)

Golang (Go) is a statically typed, compiled language developed by Google.

It’s known for its simplicity, concurrency support, and efficiency in building scalable systems.

## [Grafana](#grafana)

Grafana is an open-source analytics and monitoring platform.

It visualizes data from multiple sources and provides real-time dashboards for observability.

## [Harbor](#harbor)

Harbor is an open-source container image registry with security and access control features.

It helps manage, scan, and distribute container images across environments.

## [HTML](#html)

HyperText Markup Language (HTML) is the foundation of web content structure.

We use it to build accessible and semantic web applications.

## [IBM Storage Scale](#ibm-storage-scale)

IBM Storage Scale (formerly GPFS) is a high-performance clustered file system.

It provides scalable and reliable storage for large-scale data and HPC environments.

## [Jupyter/JupyterLab/JupyterHub](#jupyterjupyterlabjupyterhub)

Jupyter tools enable interactive computing and data analysis using notebooks.

They support collaborative research and reproducible scientific workflows.

## [Kubernetes](#kubernetes)

Kubernetes is an open-source platform for automating container deployment, scaling, and management.

It orchestrates modern cloud-native applications efficiently across clusters.

## [Linux](#linux)

Linux is an open-source operating system known for its stability, flexibility, and security.

It powers servers, clusters, and cloud environments across industries.

## [Nextflow](#nextflow)

Nextflow is a workflow management system designed for scalable and reproducible scientific pipelines.

It simplifies running complex analyses across multiple computing environments, including cloud and HPC.

## [NGINX](#nginx)

NGINX is a high-performance web server, reverse proxy, and load balancer.

It’s widely used for delivering scalable, reliable web applications.

## [Node.js](#nodejs)

Node.js is a JavaScript runtime built on Chrome’s V8 engine.

It enables efficient, non-blocking I/O for building scalable server-side applications.

## [Ollama](#ollama)

Ollama provides tools for running and managing large language models locally.

It simplifies AI model deployment on personal or private infrastructure.

## [Open-WebUI](#open-webui)

Open-WebUI is an open-source web interface framework for interacting with AI models.

It allows users to deploy, test, and manage models through a user-friendly browser interface.

## [Prometheus](#prometheus)

Prometheus is a monitoring and alerting toolkit designed for reliability and scalability.

It collects metrics and integrates seamlessly with Grafana for visualization.

## [Puppet](#puppet)

Puppet is an infrastructure automation tool for configuration management.

It ensures consistent environments through declarative configuration definitions.

## [Python](#python)

Python is a versatile programming language known for its simplicity and readability.
It’s widely used in AI, data science, web development, and automation.

## [PyTorch](#pytorch)

PyTorch is a deep learning framework offering flexible and dynamic computation graphs.
It’s widely used for AI research and production-grade model development.

## [Rancher](#rancher)

Rancher is a complete container management platform for Kubernetes clusters.

It provides centralized cluster provisioning, monitoring, and security across multiple environments.

## [React](#react)

React is a JavaScript library for building fast, interactive user interfaces.

It promotes component-based architecture and efficient rendering.

## [Redis](#redis)

Redis is an in-memory data structure store used as a database, cache, and message broker.

It delivers high performance and low latency for real-time applications.

## [RKE2](#rke2)

RKE2 (Rancher Kubernetes Engine 2) is a lightweight, fully compliant Kubernetes distribution.

It focuses on security, simplicity, and compatibility for enterprise-grade deployments.

## [SGLang](#sglang)

SGLang is a programming framework optimized for serving large language models efficiently.

It enables fast inference and resource-efficient LLM deployment.

## [Tailwind](#tailwind)

Tailwind CSS is a utility-first CSS framework for building custom designs quickly.

It allows developers to style applications directly within markup with minimal overhead.

## [TensorFlow](#tensorflow)

TensorFlow is an end-to-end open-source platform for machine learning.

It enables model training, deployment, and large-scale inference across diverse platforms.

## [TypeScript](#typescript)

TypeScript is a typed superset of JavaScript that compiles to plain JS.

It improves code reliability and scalability through static type checking.

## [vLLM](#vllm)

vLLM is an optimized LLM inference engine designed for speed and efficiency.

It supports serving large models with lower memory overhead and higher throughput.

## [Vue.js](#vuejs)

Vue.js is a progressive JavaScript framework for building user interfaces.

It focuses on simplicity, reactivity, and seamless integration with existing projects.
