[Jupyter Notebook](https://jupyter.org/) is a project to develop open-source software, open standards, and services for interactive computing across multiple programming languages.

## [Jupyter in OnDemand](#jupyter-in-ondemand)

You can run a Jupyter Notebook directly within your browser using the [OnDemand service](https://ondemand.metacentrum.cz).

Advantages

- Running as a MetaCenter job

- Extension of walltime available

## [Jupyter Hub/Lab in Kubernetes](#jupyter-hublab-in-kubernetes)

Another option is to use Jupyter Notebook through [Jupyter hub](https://hub.cloud.e-infra.cz/hub/) or [Binder hub](https://binderhub.cloud.e-infra.cz/) using Kubernetes directly in your browser. For detailed instructions, refer to the documentation [Kubernetes documentation](https://docs.cerit.io/en/docs/web-apps/jupyterhub)

Advantages

- AI Support: Some images come with AI chat support, expanding their capabilities

- Many pre-prepared images: Also contains Matlab, RStudio, and VS Code Images

- Integration with BinderHub: Access your images stored on GitHub

- SSH access support: DataScience NB with SSH access

- Resource Monitoring & Shutdown: monitoring of resource utilization and an automatic shutdown mechanism if the notebook remains unused

## [Jupyter notebook instance on cloud](#jupyter-notebook-instance-on-cloud)

This service is no longer available

The Jupyter instance on Cloud has been discontinued in favour of [Kubernetes Jupyter Notebook/Hub instance](https://docs.cerit.io/en/docs/web-apps/jupyterhub) and [Jupyter Notebook/Lab via OnDemand service](https://ondemand.metacentrum.cz).
